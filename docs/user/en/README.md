# Nimbus user docs (EN summary, offline)

Open from the desktop: N menu → **Nimbus Help** (`nimbus-help --tab guide`)
or **About Nimbus** (`nimbus-about`). No network needed.

- Full guide (Spanish): `docs/user-guide/README.md`
- Shortcut cheatsheet: `docs/user-guide/shortcuts.md`
- Index (Spanish): `docs/user/README.md`

Basics: top menu bar, Dock at the bottom, Spotlight with `Meta+Space`
(`Meta` acts as `Cmd`), semaphores on the left, Mission Control with
`Meta+W`. Limit: onboarding does not create users or partitions (ISO
installer business, out of this repo).
