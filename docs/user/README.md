# Nimbus: documentación de usuario (offline)

Toda la ayuda vive en el escritorio: menú N → **Ayuda de Nimbus**
(`nimbus-help`) o **Acerca de Nimbus** (`nimbus-about`). Sin red.

- Guía completa (español): [../user-guide/README.md](../user-guide/README.md)
- Chuleta de atajos: [../user-guide/shortcuts.md](../user-guide/shortcuts.md)
- English summary: [en/README.md](en/README.md)

Los mismos ficheros se instalan en `/usr/share/nimbus/user-guide/` y los
lee `nimbus-help` (variable `NIMBUS_GUIDE_DIR` para pruebas).
