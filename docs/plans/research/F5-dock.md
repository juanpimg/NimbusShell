# F5 Dock — Research brief (Krema + TaskManager)

1. Krema `isac322/krema`: GPL-3.0-or-later; WIP activo (62★/12 forks, 185 commits); C++23/Qt6/KF6 + `layer-shell-qt` + `kpipewire` + `plasma-workspace`; AUR `krema`, COPR, OBS, PPA, Debian 13; build CMake (`qt6-base`, `layer-shell-qt`, Kirigami, KConfig, KGlobalAccel, QtGui privada); config `~/.config/kremarc` (`MonitorMode=0..3`, `SelectedOutputs`, zoom, badges) + settings Kirigami.
2. Features: zoom parabólico (presets Natural/Quick/Relaxed/Instant/Custom + in-place), previews PipeWire GPU con lista multi-ventana + cerrar desde preview, autohide (Always/AutoHide/Dodge + `Reserve screen space`/exclusive zone), multi-monitor (Primary/All/FollowActive/Selected + per-screen), badges D-Bus + Unity SmartLauncher (Number/Dot/Off, 6 attention anims, progress bar, DND). Límites: proyecto joven, sin papelera/stacks macOS, API inestable, popup placement/badges chat parciales.
3. Fork vs pin vs tema: pin+AUR (riesgo bajo, deriva upstream) < tema Nimbus sobre Krema (recomendado: solo QML/estilo + `kremarc`, sin fork) < fork (riesgo alto: coste merge por release Plasma; solo si faltan trash/stacks o popup placement; con Ruling + upstream PR). Reutilizar MacDock: curva zoom, prefs JSON/pins, glass tokens, bounce/labels → mapear a settings Krema, no portar QML (contenedor distinto).
4. Backend: no hay D-Bus `org.kde.taskmanager` estable para docks externos; usar `libtaskmanager` de `plasma-workspace` (`TasksModel`/`LauncherTasksModel`/`WindowTasksModel`/`WaylandTasksModel`, roles `IsWindow/IsLauncher/IsMinimized/IsDemandingAttention`, métodos `requestActivate/requestToggleMinimize/requestClose/launch`); Krema ya lo integra + KService/KIO para launch/pins. Verificar con `qdbus6 --session` y cabeceras `abstracttasksmodel.h`.
5. Previews: `kpipewire` + `ScreencastingRequest` sobre KWin Wayland (thumbs vivos GPU); en VM sin GPU usar software/daño parcial; fallback ya existente en Krema: click agrupado → lista icono+lista (Ruling F5-T07 si PipeWire falla: documentar, no crashear).
6. Tema Nimbus: `packages/dock/nimbus-krema/` (preset `kremarc`, estilo Acrylic + radio Tahoe, iconos Breeze propios, separadores, trash como launcher `.desktop` + stack Downloads); pin `krema==<tag>` en `packages/dock.list` + CI rebuild por Plasma. Tests: `tests/vm/dock.sh` — 15 apps (`for i in {1..15}; do kate & done`), fps (`qmlprofiler`/`journalctl --user -u krema`), autohide (`hyprctl`→`qdbus6 org.kde.KWin`), 1-2 pantallas + escalas 100/125/150/200%, HiDPI `kscreen-doctor`; accept F5-T12: ≥55fps VM, RAM <150MB, boot <1s extra, diff golden <15%.
