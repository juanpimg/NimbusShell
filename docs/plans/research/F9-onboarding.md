# F9 — Brief técnico Onboarding/migración/updates (research, no implementa)

> F9-T01…T10 del plan Plasma. Stack: Calamares + QtQuick/Kirigami + Discover/PackageKit + Btrfs/snapper + Konsave. UI en español, identificadores en inglés.

1. **Calamares (T01):** `iso/calamares/{settings.conf,branding.desc,modules/{locale.conf,keyboard.conf,users.conf,partition.conf,packages.conf}}`; orden: `welcome>locale>keyboard>partition>users>summary>install>removeuser`. LUKS: `partition.conf: enableLuks=yes, luksName=nimbus-root`. Usuario/avatar: `users.conf + users@users` (avatar `~/.face.icon` 256px). Textos llanos en `branding.desc: strings/productName=NimbusOS, welcomeStyleCalamares`. Verificar: `calamares -d` en VM + `lsblk -f` (crypto_LUKS) + `journalctl -b | grep -i calamares`.
2. **Wizard 6 pasos (T02–T04,T06):** `apps/nimbus-welcome/{main.qml,pages/{Welcome,Lang,Wifi,Account,Appearance,Apps,Tour}.qml,state.json}` QtQuick/Kirigami `PageRow`; autostart `~/.config/autostart/nimbus-welcome.desktop` (`OnlyShowIn=KDE; X-GNOME-Autostart-enabled=true`), skip=`touch ~/.config/nimbus/welcome.done`, reanudar=`kcmshell6 kcm_nimbus` o `nimbus-welcome --page Apps`. i18n: `i18n()` + `lang/es.json` (reusar `I18n.js` MacShell). Layout Mac/Win/Nimbus (T03): presets `~/.config/nimbus/layout-{mac,win}.json` aplicados con `kwriteconfig6` + `qdbus6 org.kde.plasmashell /PlasmaShell evaluateScript`. Apps (T04): `pkcon install --allow-reinstall flathub org.foo.Bar` con `QProcess` + barra, sin bloquear.
3. **Discover simple (T07):** no fork: `plasma-discover` + modo simple vía `~/.config/discoverrc [General] CompactMode=true, ShowUnreviewed=false` y página KCM Updates que llama `pkcon refresh/update` (`org.freedesktop.PackageKit`) y `flatpak update`. Programar: `systemctl --user enable --now packagekit-offline-update.timer` o `plasma-discover-updater`. Notificar llano: `notify-send "Actualizaciones listas" "Reinicia para aplicar"`. Test: `pkcon get-updates | head; pkcon install -y hello`.
4. **Btrfs+snapper rollback (T08):** ISO exige subvolúmenes `@,@home,@snapshots` (`partition.conf` + `fstab`); `snapper -c root create-config /` + `/etc/snapper/configs/root: TIMELINE_LIMIT_*=10, NUMBER_LIMIT=20`; hook pre-update `/etc/pacman.d/hooks/50-snapper-pre.hook` (`Exec=/usr/bin/snapper -c root create -d "pre-update"`). GRUB: `grub-btrfs` + `systemctl enable grub-btrfsd` → entrada "volver a ayer" (`snapper rollback <N>` + `btrfs subvolume set-default`). Riesgos: rollback solo `/` (no `/home`), kernel viejo+dkms NVIDIA, LUKS exige desbloquear antes; test VM: romper con `pacman -U` malo → rollback → `snapper list; btrfs subvolume get-default /`.
5. **Migradores (T05,T09):** Win/Mac: `apps/nimbus-migrate/migrate.py --dry-run --source {windows/mac}` — NTFS montado ro (`udisksctl mount`), copia `Documents/Pictures`→`~/Documentos/Imágenes` (rsync, nunca sobrescribe: `--ignore-existing`), marcadores Chrome/Edge/Firefox→`~/.mozilla/firefox/*/places.sqlite` + `bookmarks.html` (script `import-bookmarks.py`), fondo→`kwriteconfig6 --file plasmarc`, equivalencias en `data/equiv.json` (Word→Writer, Photoshop→GIMP/Krita). Existentes: `transporter`/`migration-assistant` no reutilizables; usar `gio`, `secret-tool`, `rsync`. Hyprland→Plasma (T09): backup `tar -czf ~/.config/nimbusshell-backup-$(date +%s).tar.gz ~/.config/{hypr,quickshell}` + importar wallpaper/atajos/pins a `kwinrc/kglobalshortcutsrc/dock.json` + informe `nomigrable.txt` (hyprbars, `hyprctl`, MinimzeFx).
6. **Soporte/backup (T10):** `apps/nimbus-bug-report/nimbus-bug-report.sh > nimbus-bug-$(date +%F).tar.gz`: `kinfo --all`, `journalctl -b -p err`, `qdbus6 org.kde.KWin /KWin supportInformation`, `plasmashell --version; kwin_wayland --version`, `inxi -Fz`. Backup: `konsave -s nimbus-$(date +%F)` + `konsave -e perfil.knsv`; restore `konsave -i perfil.knsv -a`. Botón Ayuda: abre `docs/user/` (F11-T06) + `khelpcenter`. Gate F9: usuario nuevo sin terminal + rollback verde en VM.
