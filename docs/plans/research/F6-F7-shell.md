# Research F6-F7: Spotlight/Launchpad + Mission Control/Spaces (Plasma 6)

1. **KRunner skin fullscreen (F6-T01):** no hay API oficial fullscreen; vía `~/.config/krunnerrc` (`[General] FreeFloating=true`) + theming del view QML de `plasma-workspace/runnersview` + atajo `Meta+Espacio` en `kglobalshortcutsrc` (`krunner`). Estrategia F0-T04: QML overlay propio que embebe resultados o reestiliza el popup centrado con blur + `Esc` cierra. Latencia objetivo <50 ms (`time qdbus6 org.kde.krunner /Runner org.kde.krunner1.Match query`).
2. **Runners Nimbus (F6-T02/T03):** preferir **DBus runner** (Python template `KDE/krunner/templates/runner6python`): `.desktop` en `~/.local/share/krunner/dbusplugins/` con `X-Plasma-API=DBus`, `X-Plasma-DBusRunner-Service/Path`, interfaz `org.kde.krunner1` (`Match→a(sssida{sv})`, `Actions`, `Run`, `SetActivationToken` para Wayland). C++ (`KRunner::AbstractRunner::match/run`, `minLetterCount`, `matchRegex`) solo si el Python no da <50 ms con 10k archivos. Ranking fuzzy + `RunnerContext::addMatch` + acciones abrir/copiar/revelar.
3. **Launchpad (F6-T04/T05):** `Application Dashboard` (`org.kde.plasma.kickerdash`) es fullscreen nativo con buscador KRunner integrado pero **sin carpetas/paginación estilo Apple**; alternativa: fork GPL existente (`Plasma-AppBay`, `Linexin-Launcher`, `adhec/launchpad-plasma`) como base `org.nimbus.launchpad` en vez de layer-shell propio (R-DOCK prohíbe 2ª superficie layer-shell sin Ruling). Grid QML + modelo Kicker + `pages/pageIndicators` + drag + JSON persistencia; theming vía `desktoptheme` + tokens Nimbus.
4. **KWin Overview custom (F7-T02/T03):** MVP = Overview/Present Windows stock tematizado; efecto propio solo después. Esqueleto: `packages/kwin/effects/nimbus-overview/{metadata.json,contents/ui/main.qml}` con `QuickSceneEffect`, `EffectWindow` + `WindowThumbnail` para thumbs, `NumberAnimation/QEasingCurve` (equivale `KWin::TimeLine`), `grab` input, toggle por atajo/scripting `qdbus6 org.kde.kwin /Effects org.kde.kwin.Effects.toggleEffect`. Instalar: `kpackagetool6 --type KWin/Effect --install packages/kwin/effects/nimbus-overview`. Riesgo: API QML `org.kde.kwin.effect.*` inestable entre minors Plasma 6 → pin + CI rebuild + fallback stock.
5. **Spaces (F7-T01):** `qdbus6 org.kde.KWin /VirtualDesktopManager org.kde.KWin.VirtualDesktopManager.{count,current,setCurrent,createDesktop,removeDesktop,desktops}` (ver `kwin/src/dbusinterface.cpp`); config `kwinrc [Desktops] Number/Rows/Names_*`; atajos en `kglobalshortcutsrc` (`kwin`: Switch One Left/Right, Window One Desktop). Límite: en Plasma 6 los escritorios son **globales, no por monitor** → documentar como divergencia 1:1; animación slide vía efecto o `kwinrc [Effect-Slide]` + `reduce motion` respeta `kdeglobals`.
6. **Tests/aceptación y riesgos:** `qdbus6` smoke + `kwshot`/`spectacle -b` + `tests/screenshot-diff/compare.sh <golden> <captura>`; F6-T08 <50 ms, F7-T09 toggle <300 ms/60 fps con 20 ventanas. Riesgos: KRunner sin skin API (reestilizar popup, no fork); Dashboard sin carpetas (fork requerido); efecto QML rompe por release (pin); per-monitor Spaces imposible (Ruling); todo exige evidencia VM o no se marca.
