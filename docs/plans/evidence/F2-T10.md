## 1. Qué se entrega

- `apps/nimbus-hw/nimbus-gpu-detect`:
  - Detección precisa de vendor (NVIDIA/AMD/Intel/VM/mesa), device, slot y driver actual vía `lspci`.
  - Recomienda automáticamente el driver idóneo (`nvidia-open-dkms` para Turing+, `nvidia-dkms` para Pascal-, `mesa` para AMD/Intel).
  - Detecta modo híbrido (render offload con prime-run) y compatibilidad Wayland.
  - Formato texto llano y `--json` validado para consumo por KCM y Calamares.
- `apps/nimbus-hw/nimbus-gpu-setup`:
  - Configuración automatizada e idempotente de `nvidia_drm.modeset=1` en GRUB.
  - Carga de módulos `nvidia nvidia_modeset nvidia_uvm nvidia_drm` en `mkinitcpio.conf`.
  - Habilitación de `power-profiles-daemon.service` para gestión de energía macOS-like (performance, balanced, power-saver).
  - Manejo de suspensión gestionado vía KWin/powerdevil.
  - Modo seguro por defecto `--dry-run`/`--check`; requiere `--apply` y root para escribir cambios con backups `*.bak-<fecha>`.
- `tests/hw/test_hw.sh`:
  - Suite unitaria automatizada que verifica sintaxis, linting sin warnings, salida JSON de detección, ejecución dry-run y arnés `nimbus-hw-check.sh` (13/13 PASS).
