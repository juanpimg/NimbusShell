## 1. Qué se entrega

- `dotfiles/.config/PlasmaUserFeedback` y `dotfiles/.config/plasma/PlasmaUserFeedback`:
  - `[Global] FeedbackLevel=0` (`KUserFeedback::Provider::NoTelemetry`).
  - Idénticos byte a byte (`cmp -s`).
- `iso/profile/airootfs/usr/local/bin/nimbus-installed-setup`:
  - Desactiva telemetría en `/etc/xdg/PlasmaUserFeedback` por defecto del sistema.
  - Habilita `firewalld` en el sistema instalado.
- `iso/calamares/modules/services.conf`:
  - `firewalld` habilitado en `systemd.enabled`.
- `iso/calamares/modules/partition.conf`:
  - Recomendación y soporte de particionado LUKS2 para cifrado de disco completo.
- `scripts/nimbus-privacy`:
  - Script idempotente sin root para desactivar telemetría y purgar `~/.local/state/UserFeedback.*`.
  - Modos `--check` (dry-run) y aplicación real.
- `scripts/nimbus-flatpak-perms`:
  - Política de aislamiento Flatpak por app sin permisos host ciegos (`--nofilesystem=host --nofilesystem=home`).
- `tests/security/test_security.sh`:
  - Suite unitaria automatizada que verifica todo el esquema de seguridad (integrada en CI).
- `tests/vm/security-check.sh`:
  - Arnés de verificación para ejecución dentro de VM.
