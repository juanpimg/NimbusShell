# Evidencia F5-T04 — Magnificación parabólica y bounce del Dock

- **Fecha:** 2026-11-02
- **Estado:** CERRADO / VERIFICADO
- **Evidencias visuales:** `docs/plans/evidence/matrix-out12/01-dock-hover.png`

## 1. Resolución del puntero y validación visual

En la prueba de out12 con sesión instalada y arnés de puntero corregido:
- **Hover con magnificación parabólica:** PASS. Al pasar el cursor sobre el Dock, el icono bajo el puntero se amplía suavemente a 1.6× y muestra la etiqueta flotante (validado en `01-dock-hover.png`).
- **Curva parabólica:** `ZoomStyle=0` (curva suave de interpolación en vecindad de 3 iconos contiguos) con `MaxZoomFactor=1.6`.
- **Bounce al abrir:** TaskManager backend anima el icono al ser lanzado antes de fijar el punto indicador de ejecución (running dot).

## 2. Configuración en `packages/dock/kremarc-nimbus`

```ini
[General]
IconSize=48
IconSpacing=4
MaxZoomFactor=1.6
ZoomStyle=0
```
