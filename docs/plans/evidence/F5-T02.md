# F5-T02 — Tema visual Nimbus (tile/zoom/glass, live 2026-10-31)

## Config aplicada (`kremarc-nimbus`, md5 guest==host `2716a868…`)
Tile `IconSize=48` + `IconSpacing=4`, zoom parabólico `MaxZoomFactor=1.6`
`ZoomStyle=0` (Parabolic), abajo `Edge=1`, flotante `Floating=true`
`FloatingMargin=8`, esquinas `CornerRadius=12`, acrílico Tahoe
`BackgroundStyle=3` (Acrylic) `BackgroundOpacity=0.6`, siempre visible
`VisibilityMode=0` + `ReserveScreenSpace=true`, previews 200px/500ms.

- `spikes/f5/f5-dock-desktop.png`: escritorio limpio (Show Desktop) + dock
  centrado abajo, flotante, fondo acrílico oscuro, 9 iconos con running dots.
- `spikes/f5/f5-dock-konsole.png`: dock sobre ventanas, sin artefactos.
- `spikes/f5/f5-dock-restored.png`: tras ciclo autohide→base, dock idéntico
  (tile 48, abajo, flotante, acrílico). Persistencia del fichero verificada
  por md5 tras cada reinicio de krema.
