# Evidencia F1-T03 — `install.sh` modular con perfiles

Rama: `plasma/f1-restructure`. Fecha: 2026-10-31. Host: CachyOS (dev).

## Comandos

```bash
git mv install.sh legacy/hyprland/install.sh   # + aviso legacy y rutas por variable
# nuevo dispatcher raíz + lib/{common,plasma,kwin,themes,dock,apps,verify}.sh
# packages/plasma.list desde docs/plans/research/F2-base.md (§1+§8)
for f in install.sh legacy/hyprland/install.sh lib/*.sh; do bash -n "$f"; done
shellcheck -S warning install.sh legacy/hyprland/install.sh lib/*.sh
./install.sh --help                              # exit 0
./install.sh --bogus                             # exit 2
./install.sh --profile=malo --check              # exit 2
./install.sh --check                             # perfil plasma, exit 1
./install.sh --profile=legacy-hypr --check       # delega en legacy, exit 1
./install.sh --profile legacy-hypr --check       # forma con espacio, exit 1
./legacy/hyprland/install.sh --help              # directo, exit 0
```
