## Resultados de `test_compare.sh` (PNG sinteticos 32x32 via PIL)

| Caso | Resultado |
|---|---|
| Identicas | `diff: 0.00%`, exit 0 |
| Distintas (negro vs claro) | `diff: 100.00%`, exit 1 |
| Distintas con `--threshold 100` | exit 0 |
| Tamano distinto (32x32 vs 16x16) | error claro, exit 2 |
| Crop igual `0,0,16,16` | `diff: 0.00%`, exit 0 |
| Fichero ausente | error claro, exit 2 |
| `--help` | exit 0 |

`capture.sh` sin VM: `VM apagada o sin monitor HMP: no existe .../hmp.sock`, exit 2.
`--out diff.png`: mapa rojo/negro generado correctamente.

## Limitacion

Goldens de macOS Tahoe pendientes de capturas aportadas por el usuario en
`tests/golden/local/` (no se distribuyen, R-APPLE). El diff automatico queda
verificado con sinteticos; el primer golden real se generara con `capture.sh`
cuando la VM Plasma exista (F2).
