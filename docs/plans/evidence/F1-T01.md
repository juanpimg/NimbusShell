# Evidencia F1-T01 — Rama, tag y congelación del legacy

Rama: `plasma/f1-restructure`. Fecha: 2026-10-31.

## Comandos

```bash
git tag -a hyprland-final -m "último estado Hyprland"
git tag -l -n1 hyprland-final
mkdir -p legacy/hyprland
git mv dotfiles legacy/hyprland/dotfiles
find legacy/hyprland/dotfiles -type f | wc -l
git add legacy/hyprland/README.md
git commit -m "feat(F1-T01/T02): congelar Hyprland y estructura Plasma"
```
