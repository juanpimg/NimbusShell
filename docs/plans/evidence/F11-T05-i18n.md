# Evidencia F11-T05 — i18n unificado, guía y chuleta

## Qué se implementó
- Dueño único `scripts/nimbus-i18n` (bash `set -u` + Python stdlib, sin
  root, sin red): `--extract` (regenera `i18n/*.ts`), `--check` (falla si
  hay TS desincronizado o cadenas sin traducir), `--stats` (cobertura por
  contexto), `--cheatsheet` (regenera `docs/user-guide/shortcuts.md`
  desde `dotfiles/.config/plasma/kglobalshortcutsrc`).
- `i18n/nimbus_es.ts` + `i18n/nimbus_en.ts` (Qt Linguist XML, 18 contextos
  por fichero, 341 cadenas únicas, 403 mensajes, 0 `type="unfinished"`):
  Welcome (QML + dict `I18n.js`), Spotlight, Apps, KCM ×6, bar ×7.
  Español fuente; inglés 100 % (símbolos e IDs internos con identidad).
- `docs/user-guide/README.md` (primeros pasos 7 pasos, Spotlight/Apps/
  Mission Control/Dock/KCM, claro-oscuro-acento, accesibilidad, atajos,
  updates/rollback, troubleshooting; límites marcados `Límite`),
  `docs/user-guide/shortcuts.md` (33 atajos macOS→Plasma, Meta=⌘, sin Ctrl
  nuevos salvo Meta+Ctrl heredados de Spaces/bloqueo) y `docs/i18n.md`
  (dueño, flujo, cómo añadir idioma).
- `tests/i18n/test_i18n.sh` (5 pasos, I18N VERDE) + gancho read-only en
  `scripts/ci.sh` (`nimbus-i18n --check` y el test).

## Verificación (host, solo lectura, HOME temporal)
- `scripts/nimbus-i18n --extract --stats --check` →
  `CHECK_OK: 341 cadenas es/en, 0 unfinished, TS sincronizados`.
- `tests/i18n/test_i18n.sh` → I18N VERDE (403+403 mensajes, cobertura
  idéntica, `--check` verde, 33 atajos ≥20, 0 Ctrl nuevos, 0 enlaces rotos).
- `bash -n` + `shellcheck -S warning` limpios en `scripts/nimbus-i18n` y
  `scripts/ci.sh`; TS parseados con `xml.etree` (sin lupdate en PATH de
  usuario; hay `/usr/lib/qt6/bin/lupdate`, no usado para no requerir Qt
  tools en CI).
- Re-ejecución idempotente: `--extract` y `--cheatsheet` regeneran byte a
  byte (`--check` verde tras re-ejecutar).

## Gaps (honestos, también en la guía)
- Etiquetas dinámicas del sistema (nombres de apps/redes/aparatos,
  tooltips de bandeja, resultados KRunner) siguen el locale del sistema.
- `Cmd+1…4` globales reservados pero sin binding global cableado.
- Sin snapper/Discover/Orca, sus secciones lo indican y degradan a
  terminal/manual (comportamiento ya existente, ahora documentado).
