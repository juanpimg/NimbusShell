# i18n NimbusShell (F11-T05)

Dueño único: [`scripts/nimbus-i18n`](../scripts/nimbus-i18n) (bash +
Python stdlib, `set -u`, sin root, sin red). Los catálogos viven en
[`i18n/`](../i18n/) como Qt Linguist XML (`nimbus_es.ts`, `nimbus_en.ts`):
un contexto por fichero fuente, `source` exacto y traducción completa
(0 `type="unfinished"`). El español es la lengua fuente; el inglés traduce
el 100 %.

## Cobertura

- `apps/nimbus-welcome` (`Welcome.qml` + dict de `I18n.js`), `apps/nimbus-spotlight`,
  `apps/nimbus-apps`, `packages/kcm/kcm_nimbus/ui/*` (vía `i18n()`),
  `packages/shell/nimbus-bar/qml/*` (Menu, ControlCenter, Calendar,
  GlobalMenu, StatusArea, OSD, Bar).
- Incluye nombres accesibles (lector de pantalla), placeholders y
  fragmentos compuestos en JS (p. ej. `Latencia: … resultados`, ` y cerrar`).

`Límite`: las etiquetas dinámicas del sistema (nombres de apps, redes,
aparatos, tooltips de bandeja, resultados de KRunner) siguen el locale del
sistema y no están en los catálogos.

## Flujo

```sh
scripts/nimbus-i18n --extract     # regenera i18n/*.ts desde QML/JS
scripts/nimbus-i18n --check       # falla si hay TS desincronizado o sin traducir
scripts/nimbus-i18n --stats       # cobertura por contexto (solo lectura)
scripts/nimbus-i18n --cheatsheet  # regenera docs/user-guide/shortcuts.md
scripts/nimbus-i18n --export html # genera docs/user-guide/shortcuts.html
scripts/nimbus-i18n --export pdf  # genera docs/user-guide/shortcuts.pdf si hay
                                  # weasyprint o pandoc+motor; si no, aviso y exit 0
```

`--check` es solo lectura y corre en CI (`scripts/ci.sh`). Falla con
mensaje accionable si: falta un `.ts`, hay XML inválido, hay traducciones
vacías/sin terminar, el `.ts` no cubre una cadena extraída, sobran
cadenas obsoletas, es/en difieren o falta traducción inglesa.

## Cómo añadir un idioma

1. Añade la columna en el dict `EN` de `scripts/nimbus-i18n`
   (o crea `LANG = {...}` junto a él y un `ts_write(lang, …)` para el
   nuevo código; el patrón ya está: `es` usa la fuente, `en` usa el dict).
2. Ejecuta `--extract` y comprueba `--stats` (el nuevo idioma debe igualar
   la cobertura es).
3. Extiende `--check`/tests para exigir el nuevo `.ts` y documenta el
   idioma en la guía ([user-guide/README.md](user-guide/README.md)).
4. Si el idioma necesita plural o género distinto, usa `qsTrn`/`i18n`
   con `%1` en el QML antes de extraer (los marcadores `%1`, `%2` se
   conservan tal cual en la traducción).
