# packages/kwin — decoración, efectos y scripts KWin

- **Qué va:** preset Klassy Tahoe (semáforos 12px, titlebar 28px),
  efecto `nimbus-overview`, scripts (`nimbus-zoom`, `nimbus-spaces`),
  `kwinrulesrc` documentadas. IDs: `org.nimbus.*`.
- **Qué no:** forks de KWin (parches mínimos con `NimbusOS Ruling` y
  propuesta upstream). Sin binds `CTRL-*` nuevos (R-CTRL: Meta/Super).
