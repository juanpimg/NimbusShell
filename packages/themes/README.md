# packages/themes — fundación visual Nimbus

- **Qué va:** design tokens (`nimbus-tokens`: colores, radios 24/12, Inter
  12/13, acento), presets Kvantum/Klassy/Colorizer, iconos propios,
  wallpaper Sequoia NPS, sonidos propios, presets Window Buttons6.
  Versiones pinneadas, sin `latest`.
- **Qué no:** activos Apple (R-APPLE: nada de logos, SF, wallpapers o
  sonidos suyos). Temas GPL inspirados (WhiteSur, Klassy, Kvantum) solo con
  atribución y arte original.
