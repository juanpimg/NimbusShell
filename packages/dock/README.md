# packages/dock — Dock layer-shell (`org.nimbus.dock`)

Única deuda layer-shell permitida (R-DOCK): base/fork/theme Krema con
backend TaskManager (`org.kde.taskmanager`), magnificación parabólica,
autohide, pins persistentes, papelera y prefs.

- **Qué va:** fork pinneado o dependencia pinneada + tema Nimbus, decisión
  registrada (F5-T01), `LICENSE` y atribución.
- **Qué no:** zoom dentro del panel (bug KDE 495100); otro componente
  layer-shell sin Ruling nueva.
