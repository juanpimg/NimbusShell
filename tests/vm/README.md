# tests/vm — harness de VM (QEMU/KVM)

Scripts de instalación (`install.sh`), aceptación por superficie
(`topbar.sh`, `windows.sh`, `dock*.sh`, `spotlight*.sh`,
`overview*.sh`) y métricas (boot, RAM, fps, journal sin errores críticos).

- **Qué no:** goldens (van en `tests/golden/`) ni pruebas de puntero
  finas (van en `tests/interaction/`).
