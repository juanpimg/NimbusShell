# apps/nimbus-migrate (`org.nimbus.migrate`)

Migradores con dry-run, sin sobrescribir y con rollback: desde
Windows/Mac (documentos, marcadores, fondo, equivalencias) y legacy
Hyprland→Plasma (backup de `~/.config/hypr`/`quickshell`, wallpaper,
atajos, pins; informe de lo no migrable, F9-T09).

- **Qué no:** instalación del sistema (es Calamares/`iso/`) ni snapshots
  del sistema (es snapper/Btrfs, F9-T08).
