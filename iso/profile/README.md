# iso/profile — perfil netinstall pinneado

Perfil archiso/CachyOS reproducible: `profiledef.sh`, `packages.x86_64`
(Plasma 6, KWin, KRunner, SDDM, Klassy, Kvantum, Calamares, drivers),
`pacman.conf` con snapshot pinneado. `mkarchiso` produce la ISO (hash
registrado, F2-T06).

- **Qué no:** paquetes AUR sin pin ni versiones `latest`.
